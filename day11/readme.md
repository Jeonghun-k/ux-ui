## 오토레이아웃 정리

프레임에 "자식들을 자동 배치하라"는 규칙을 거는 기능. CSS `display:flex`와 같다.

### 설정 4가지

| Figma | CSS |
|---|---|
| 흐름 (세로 / 가로) | `flex-direction: column / row` |
| 간격 | `gap` |
| 패딩 | `padding` |
| 정렬 (3×3 격자) | `justify-content` + `align-items` |

### 중첩 = DOM 트리

바깥 프레임은 `gap 32`, 안쪽 `Form`은 `gap 12`.
**한 flex 컨테이너 안에서는 gap이 하나뿐이므로, 간격을 다르게 주려면 프레임을 하나 더 만들어야 한다.**
`Form`을 만든 이유가 이것.

### 쓰는 이유

1. **수정 비용** - 요소 추가,삭제 시 나머지가 자동 배치
2. *8텍스트 길이 대응** - 이름,상품명,번역문 길이가 변해도 안 깨짐
3. **반응형의 전제** - 폭이 바뀌어도 규칙대로 재배치

> 오토레이아웃은 예쁘게 만드는 기능이 아니라 **유집수를 위한 기능**이다.
> 코드에서 하드코딩 대신 변수를 쓰는 이유와 같다.

## 막힌점 + 해결

### 1. Shift + A를 눌려도 자식 프레임이 안 생김

**원인** - Shift + A는 "만들기"가아닌 **"감싸기"** 단축키.

| 선택한 것 | 결과|
|---|---|
| 프레임 1개 | 그 프레임에 오토레이아웃이 **적용됨** (자식 안 생김) |
| 오브젝트 여러 개 | 그것들을 **감싸는 새 프레임 생성** |

### 2. 비밀번호 텍스트가 두 줄로 깨짐

**원인** - 인스턴스 안 텍스트 폭이 `고정`이라 넘침.
**해결** - 원본 컴포넌트의 텍스트를 `컨테이너 채우기`로 변경 -> 인스턴스 2개에 자동 반영.

### 3. 콘텐츠가 화면 중앙까지 밀려 내려감

**원인** - 패딩 `상 120`은 맞지만 세로 정렬이 **가운데**로 잡혀있었음.
**해결** - 3x3 격자 맨 윗줄 가운데 선택. `justify-content: center` -> `flex-start`.
