# 타이포그래피 기초
1. 타이포그래피
   1. 크기위게, 줄간격, 자간을 일컫는 말이다
   2. 중요한 이유 : 화면이 정돈되어보이는 효과가 있다
2. 타입 스케일(크기 위계)
   1. 폰트 크기를 일정한 배율로 만든다
     - ex) `font-size : 23px`처럼 그때마다 찍는 대신, `--text-lg: 20px`같은 디자인 토큰 집합을 만들어두고 꺼내쓰는 것이다
  
3. 줄간격
   1. 본문 : 1.5 ~ 1.6 (한글은 1.6~1.7)
   2. 제목 : 1.1 ~ 1.3 (크기 자체가 여백을 만들어줌)
   3. 반드시 단위 없이 쓰기 `line-height : 1.5`✅ / `line-height : 24px`❌

4. 줄 길이(line length)
   1. 한줄에 영문 50 ~ 75자, 한글 30 ~ 40자가 적절하게 가독성 좋은 길이이다
   ```css
   .article { max-width : 65ch;} /* ch = "0"문자 하나의 너비*/
   ```

5. 자간 (letter-spacing)
   1. 본문은 안건드린다
   2. 큰 제목은 살짝 좁게 : `letter-spacing : -0.02em` -크게 키우면 글자사이가 상대적으로 벌어져보임
   3. 작은 대문자/라벨은 살짝 넓게 : `letter-spacing : 0.05em`
