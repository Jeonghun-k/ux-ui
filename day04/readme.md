# 타이포그래피 기초 : 위계질서
1. 타입 스케일
   1. 글자 크기를 정해진 배수에서 선택한다
   2. `12/14/16/20/24/32/48`
2. 위계를 `굵기+색`
   1. 강조 : `#111827 (거의 검정)` + `font-weight: 600`
   2. 본문 : `#374151 + 400`
   3. 보조/캡션 : `#6b7280 + 400`, 크기 한단계 아래
3. 줄간격
   1. 본문 : 16px = 1.6~1.7
   2. 큰 제목 : 32px이상 = 1.2~1.3
4. 한 줄 길이
   1. 45~75자 이내
   2. max-width : 65ch하면 글자 폭 65로 고정됨
   ```css
   article { max-width: 65ch; margin: 0 auto; }
   ```

## 실습
한 파일에 아래 4줄 텍스트를 넣고, 폰트는 딱 하나만 쓰면서 크기·굵기·색만으로 위계를 만들어보세요.
```
NEW              ← 배지 (12px, 600, 파랑)
무선 노이즈캔슬링 헤드폰   ← 제목
음질과 착용감을 동시에 잡은 플래그십 모델입니다.  ← 설명
₩329,000  ·  무료배송     ← 가격 + 보조정보
```

규칙
1. 크기는 12 / 14 / 16 / 20 / 24px 중에서만 고르기
2. 색은 #111827 / #374151 / #6b7280 3개만 사용
3. line-height를 제목과 설명에 다르게 적용해보기


실습 코드는 파일로 업로드 해둠
